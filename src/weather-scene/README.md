# IWESR System：台灣大氣色系模組

IWESR 是首頁天氣卡片呼叫的獨立視覺引擎。既有卡片仍負責文字、按鈕、圖示與排版；場景元件覆蓋整張即時天氣卡片，並設定為不可接收觸控事件。卡片下半部另疊加柔和的透明白色漸層，只提升數據可讀性，不切斷場景。

## 計算流程

`weatherObservationToSceneInput` 將 Open-Meteo 的原始數值、目前縣市、AQI 與系統減少動態效果設定轉成統一輸入。所有百分比在輸入層維持 0–100。

`resolveWeatherScene` 是無副作用純函式，依序處理：

1. 根據太陽高度、日出日落與時間解析時段。
2. 取得時間基礎色盤。
3. 疊加季節、區域、地形與天氣修正。
4. 以連續函式計算濕度、能見度、AQI、霧霾與山景衰減。
5. 把總雲量分配到高、中、低三層雲。
6. 計算降水、風向、雲速與畫質級別。
7. 將所有輸出限制在合理範圍。

`condition` 與日夜狀態彼此獨立。`sunny` 只描述雲況；`resolveTimePhase` 會優先採用太陽高度，其次比較目前時間與日出日落，最後才使用輸入的備援時段。引擎據此輸出 `celestial.mode`、透明度、光暈、亮度、飽和度及縮放，UI 不自行判斷小時。

顏色在 HSL 空間插值，不直接對 HEX 做數值運算。`interpolateScene` 可供後續動畫控制器在氣象更新時平滑過渡。

## 視覺層

- `SkyLayer`：三段天空色與柔和地平線光帶。
- `CloudLayer`：高層帶狀雲、中層橢圓雲群、低層厚雲，三者不是同圖複製。
- `TerrainLayer`：遠山與近山獨立衰減。
- `FogLayer`：由濕度、能見度、AQI 與盆地條件共同控制。

`surface` 另輸出卡片環境色、透明度與主／次文字色。夜間使用很淡的藍灰白，使資訊卡吸收天空環境色但維持原有對比。

## 畫質模式

- 省電：一層雲、簡化地景，動畫倍率最低。
- 標準：高層與中層雲、山景與霧。
- 高畫質：完整三層雲、山景與霧。
- 自動：第一階段以系統「減少動態效果」為主要依據；後續可再接低耗電模式與裝置能力。

## 驗證

執行 `npm run typecheck` 與 `npm run test:iwesr`。測試涵蓋十個指定台灣情境、數值範圍、合法色彩、霧／山／雲規則，以及 21 個場景插值進度。

## 第一階段限制

本階段刻意不加入雨滴粒子、雷光、城市前景視差與太陽／月亮動畫，以免在完成實機視覺校正前增加效能成本。引擎已輸出這些後續層需要的參數。
